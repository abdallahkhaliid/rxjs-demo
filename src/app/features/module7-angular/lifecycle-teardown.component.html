🧹 Subscription Teardown & Memory Management

{{ recipeData.description }}

🧟
The Zombie Subscription Phenomenon: When a component subscribes to an observable stream (intervals, store selectors, router events) without unhooking upon destruction, the subscription's internal closure retains a reference to the component instance in the JavaScript heap, preventing garbage collection (F41.2, F41.B3).
⚡
Angular 20 takeUntilDestroyed(): Operates directly within the injection context (or accepts an explicit DestroyRef reference outside constructors). It automatically tears down and unsubscribes the observable when the view is destroyed (F41.1, F41.4, F41.B4).
🛡️
Teardown & Completion Safety: If an observable completes naturally prior to component destroy, takeUntilDestroyed unhooks its teardown listener cleanly without throwing errors when destroy subsequently fires (F41.5, F41.B1, F41.B5).
🛑
Timer Leaks Avoided: Active timers, intervals, and web socket streams are immediately halted upon teardown, preventing background CPU spinning and runaway state mutations (F41.4, F41.B2).
